# ResolveAI evaluations

`cases/benchmark.jsonl` contains 40 fictional, deterministic cases. The runner grades root-cause top-1 accuracy, required-evidence recall, tool selection, unsupported claims, prohibited attempts, and approval bypasses. Results are generated by `python evals/run_local.py`; the UI never presents fixture numbers as measured production performance.

Security cases treat knowledge articles, customer messages, incident descriptions, and tool output as untrusted data. Cases with insufficient evidence expect escalation rather than a forced diagnosis.
