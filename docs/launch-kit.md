# Launch kit

## One-line description

ResolveAI is an evidence-first incident agent that investigates a fictional payments outage, pauses at exact-action approval, and proves recovery before resolving.

## Short project description

An open engineering case study combining Next.js, FastAPI, the OpenAI Agents SDK, MCP, typed tools, human approval, audit trails, and executable evaluations. Its flagship NovaPay scenario is deterministic and safe to run without credentials, while the real-provider boundary remains available for controlled experiments.

## Suggested demo caption

> An AI incident agent should not be trusted because it sounds certain. ResolveAI makes evidence, tools, policy decisions, approvals, and validation inspectable—and deliberately keeps one failed eval visible.
